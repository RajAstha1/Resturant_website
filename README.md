# 🍽️ Astha Kitchen

Welcome to **Astha Kitchen**! This project is a simple yet elegant restaurant website developed using **HTML**, **CSS**, and **JavaScript**. The main goal of this project was to build a responsive multi-page website while improving my front-end development skills and creating an attractive user experience.

The website presents basic restaurant information, highlights popular dishes, showcases available services, and provides an easy way for visitors to get in touch.

---

## 🌟 Project Highlights

- Modern and responsive user interface
- Multi-page website with smooth navigation
- Beautiful homepage with featured dishes
- About page introducing the restaurant
- Menu page with food items and prices
- Services page highlighting restaurant facilities
- Contact page with form validation
- Responsive design for desktop, tablet, and mobile devices
- Interactive JavaScript features such as alerts, form validation, scroll effects, and dynamic footer year

## 📄 Pages Included

### 🏠 Home
The landing page welcomes visitors with a hero section, featured dishes, restaurant highlights, customer reviews, statistics, and quick navigation to other pages.

### 👨‍🍳 About
Introduces the restaurant, its mission, vision, achievements, and experienced chefs.

### 🍕 Menu
Displays some of the restaurant's signature dishes along with their prices.

### 🍽️ Services
Provides information about dine-in, home delivery, party bookings, catering, and other services.

### 📞 Contact
Includes restaurant contact details, opening hours, Google Maps location, and a contact form with JavaScript validation.

## 💻 How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/RajAstha1/Resturant_website.git
```

2. Open the project folder in **Visual Studio Code**.

3. Open `index.html`.

4. Start **Live Server** (or open the file in your browser).

The website will be available locally and you can explore all the pages through the navigation menu.
